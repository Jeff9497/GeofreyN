# geofreynjoroge.com

Personal portfolio for Geofrey Njoroge Kamau — Computer Scientist & AI Researcher based in Nairobi, Kenya.

## Stack

- **Next.js 15** — App Router
- **TypeScript**
- **Tailwind CSS v3**
- Deployed on **Vercel** → `geofreynjoroge.com`

## Routing

| Path | Content |
|---|---|
| `/` | This portfolio |
| `/blog` | Research blog (github.com/Jeff9497/Blog) |
| `/portfolio` | Previous portfolio (proxied via Vercel rewrite) |

## Dev

```bash
npm install
npm run dev
```

## Deploy

Push to `main` — Vercel auto-deploys. Set custom domain `geofreynjoroge.com` in Vercel project settings.
